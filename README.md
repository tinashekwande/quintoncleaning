# Quinton Chinoz Projects — Professional Deep Cleaning Services

Official commercial website and project portfolio for **Quinton Chinoz Projects**, based in Kraaifontein, Cape Town, Western Cape, South Africa.

## 🧹 Services
- **Carpet & Area Rug Deep Cleaning**: Heavy soil, high-traffic grime, and allergen extraction.
- **Couch & Upholstery Deep Cleaning**: Spot treatment, stain lifting, fabric sanitisation, and odour removal.
- **Mattress Deep Cleaning**: Dust mite, sweat, dead skin, and allergen extraction for a hygienic sleep environment.
- **Tile & Grout Deep Cleaning**: Dirt lifting, chemical rinse, and sealant application for high-traffic hard surfaces.
- **Vehicle Interior Upholstery**: Fabric car seat stain extraction and interior shampooing.

## 🚀 Key Features
- **Modern Responsive Design**: Crafted with a bespoke CSS design system (Montserrat + Cormorant Garamond typography, luxury charcoal and rooftop-red brand accents).
- **Interactive Project Showcase**: A dedicated [gallery.html](gallery.html) displaying 40+ verified cleaning project transformations with real-time category filtering (All, Couches, Carpets, Mattresses, Vehicles) and a responsive full-screen lightbox modal.
- **Lead Generation**: 
  - Glassmorphic quote request form in the hero section with instant WhatsApp routing and bot protection (honeypot field).
  - Floating direct WhatsApp enquiry buttons with pre-filled service messages.
- **Zero-Dependency Core**: Pure semantic HTML5, custom CSS3, and vanilla ES6+ JavaScript. Fast loading and performance-optimised.
- **SEO & Accessibility**: Complete Open Graph, Twitter Cards, Schema.org LocalBusiness structured data, XML sitemap, obots.txt, and WCAG AA accessibility focus states.
